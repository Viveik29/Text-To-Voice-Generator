News Analyst — Project Flow colorful overview

End-to-End Project Flow

TEXT_TO_VOICE_GENERATOR — Streamlit app that turns news (paste or newspaper PDF) into a Hindi educational pack via Claude, then saves notes, assets, and narration audio under a headline-named folder. A separate Text-to-Voice tab converts any text to speech.

Start: streamlit run app.py  ·  API: ANTHROPIC_API_KEY in .env

User Input PDF / OCR Extract Claude AI Artifacts & Audio TTS Tab

Visual system map

0 Launch App

Run streamlit run app.py · set ANTHROPIC_API_KEY in .env

Tab A — News Analyst
Article → Claude educational pack → Hindi audio UPSC / SSC / Banking / State PCS focused study material
Tab B — Text to Voice
Any text → Piper (EN) or gTTS (Hindi / Bhojpuri) Independent of Claude — no API key needed for TTS only

1 Choose Input Source

Paste text Paste full article. Optional keyword filter if multiple stories in one paste.
Upload PDF Newspaper / editorial PDF. Enable Use OCR for scanned or custom-font pages.

2 PDF Path — Get Clean Article Text

Three ways to get usable article text. Bad OCR is skipped, never forced into Claude:

Fetch by headline OCR finds headline line → same-column body until next headline → one clean TXT
Extract → TXT Full-page OCR column split → quality gate → save under extracted_txt/
Paste fallback Paste from newspaper website if OCR/layout fails (not Ctrl+C from PDF viewer)

Pick one quality-passed TXT → sent to Claude via article_txt_path

3 Analyze & Generate → Claude

app.py → pipeline/runner.py → pipeline/analyzer.py → Anthropic Claude (streaming)

  • Quality check on text before API call
  • Hindi educational multi-asset pack — Parts 1–16 (study notes, YouTube script, MCQs, mind map, slides, social posts…)
  • Prompts from agents/news_analyst/ · schema in pipeline/schemas.py

4 Save Claude Response — Headline Folder

All outputs saved under a folder named after the article headline (filesystem-safe slug):

artifacts/Santiago_to_Shopian_and_Delhi/

claude_response.json claude_response.md analysis.json notes.md report.pdf educational_assets/ hindi_script.txt hindi_summary.txt *_hindi_narration.mp3

5 Hindi Narration Audio

Spoken script from Claude → pipeline/audio.py → tts_engine.py (gTTS Hindi) → MP3 in headline folder

UI shows educational pack preview + download buttons for PDF, JSON, script, and audio

6 Text-to-Voice Tab (parallel path)

Independent of Claude — paste any text, pick voice, click Generate Audio

  • English voices → Piper ONNX (offline, CPU)
  • Hindi / Bhojpuri → Google gTTS (online)
  • Output saved under output/

On-disk folders (what gets created)

extracted_txt/<pdf_name>/ 01_article_title.txt 02_another_article.txt index.json ← OCR article TXT (quality-passed only)
artifacts/<headline_slug>/ claude_response.json claude_response.md report.pdf educational_assets/ 01_hindi_study_notes.md … 16_expected_questions.md *_hindi_narration.mp3 ← full Claude pack per article
